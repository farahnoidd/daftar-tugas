    Penjelasan Teknologi

    Git dan GitHub

    Git adalah version control untuk mencatat riwayat perubahan kode. Di proyek ini saya memakai commit, branch (feature/style, feature/judul-a, feature/judul-b), merge, Pull Request, penyelesaian merge conflict, serta push dan pull ke GitHub. File .gitignore mencegah node_modules, dist, dan .env ikut terunggah.

    npm

    npm adalah package manager untuk mengelola library. package.json berisi daftar package dan npm scripts (dev, build, preview). dependencies dipakai saat aplikasi berjalan, sedangkan devDependencies (TypeScript, Vite) hanya untuk pengembangan. Semantic versioning berformat MAJOR.MINOR.PATCH, dan tanda ^ berarti update minor/patch boleh otomatis.

    TypeScript

    TypeScript adalah JavaScript dengan tipe statis sehingga kesalahan tipe ketahuan sebelum aplikasi dijalankan. Yang dipakai di proyek ini: primitive types (string, number, boolean), array, interface (Task), type alias dan union type (TaskStatus), serta generics (loadFromStorage<T>).

    Vite

    Vite adalah build tool dan dev server. npm run dev menjalankan server pengembangan yang cepat, sedangkan npm run build menghasilkan file siap produksi di folder dist.

    Peran Compiler, Transpiler, dan Bundler

    Compiler (tsc) memeriksa tipe pada kode TypeScript. Transpiler mengubah TypeScript menjadi JavaScript yang bisa dibaca browser (di Vite dilakukan oleh esbuild). Bundler (Vite) menggabungkan dan mengoptimalkan modul, CSS, dan aset menjadi sedikit file yang efisien.

    Environment Variables

    Konfigurasi disimpan di file .env dengan awalan VITE_, misalnya nama dan versi aplikasi. .env tidak diunggah ke GitHub, dan .env.example menjadi contoh untuk pengguna lain. Variabel VITE_ ikut masuk ke bundle sehingga terlihat publik, jadi password dan API key rahasia tidak boleh disimpan di sini.
